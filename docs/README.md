## 规划基线

- 编写日期：2026-11-05。
- 模块路径为 `github.com/tiyee/go-alipay`，与当前 Git remote 一致。
- 项目统一使用 alipay 命名，采用 `core/`、`services/`、`utils/` 分层，协议实现依据支付宝官方文档。
- 数据模型优先使用具名 struct，通用调用、编解码和通知结果通过泛型扩展；枚举采用具名类型与带类型的常量。
- 未内置 API 可由用户在独立包中实现，使用公开的泛型 Operation、编解码器及 Client，不需要修改 SDK。
- 日志统一采用标准库 `log/slog`，支持任意 `slog.Handler` 实现注入，未配置时保持静默。
- 本方案建议先实现传统网关 OpenAPI 的交易闭环，再补充证书并发布首个测试版本；V3 为独立后续阶段。
- 项目基线固定为 Go 1.27，`go.mod` 声明 `go 1.27.0`，开发与 CI 使用 1.27 系列最新稳定补丁。
- 优先采用适用的 Go 1.27 正式能力，包括泛型方法、JSON v2、标准库深拷贝与并发测试工具，具体规则见整体架构。
- 当前已建立模块与版本配置；接口代码、SDK 测试与真实支付调用尚未实施。
